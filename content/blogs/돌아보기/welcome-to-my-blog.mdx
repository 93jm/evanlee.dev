# 블로그에 오신 것을 환영합니다

안녕하세요! 제 블로그에 방문해주셔서 감사합니다.

## 블로그 소개

이 블로그는 제가 개발하면서 배운 것들, 경험한 것들을 공유하기 위한 공간입니다.

### 다룰 주제들

- **Frontend Development**: React, Next.js, TypeScript 등
- **Backend Development**: Node.js, Database 설계 등
- **DevOps**: CI/CD, 배포 자동화 등
- **개발 일상**: 개발하면서 겪은 문제 해결 과정

## 기술 스택

현재 이 블로그는 다음 기술들로 구성되어 있습니다:

```typescript
const techStack = {
  framework: "Next.js 15",
  styling: "Vanilla Extract",
  content: "MDX",
  deployment: "Vercel",
};
```

### 왜 이 스택을 선택했나요?

1. **Next.js 15**: 최신 React 기능과 뛰어난 성능
2. **Vanilla Extract**: 타입 안전한 CSS-in-TS
3. **MDX**: 마크다운 안에서 React 컴포넌트 사용 가능
4. **Vercel**: 간편한 배포와 빠른 CDN

## 마무리

앞으로 유익한 글들을 많이 공유하도록 하겠습니다.
지켜봐 주세요!
