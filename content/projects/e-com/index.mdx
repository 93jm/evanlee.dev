## Overview

E.com은 Next.js App Router를 활용해 X.com의 주요 UI 흐름을 프론트엔드 중심으로 구현한 학습 프로젝트입니다.

## Role

기획, 화면 구현, 상태 관리, mock API 구성을 직접 담당했습니다.

## Implementation

Next.js, React, TypeScript를 기반으로 라우팅과 화면 구조를 만들고 Zustand, Context API, MSW를 함께 사용했습니다.

## Notes

이 문서는 v1 프로젝트 데이터를 v2 콘텐츠 모델로 옮긴 초안입니다. 상세 구현 회고와 배운 점은 이후 보강합니다.
