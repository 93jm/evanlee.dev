## Overview

Exporterhub는 Prometheus 커뮤니티 사용자를 위한 Exporter 정보를 제공하는 허브 사이트입니다.

## Role

오픈소스 컨트리뷰터로 프론트엔드 구현과 개선 작업에 참여했습니다.

## Implementation

React, JavaScript, Styled Components 기반 코드베이스에서 화면과 API 연동 흐름을 다뤘습니다.

## Notes

이 문서는 v1 프로젝트 데이터를 v2 콘텐츠 모델로 옮긴 초안입니다. 구체적인 기여 범위는 이후 보강합니다.
