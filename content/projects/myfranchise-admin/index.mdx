## Overview

마이프차 Admin은 B2B와 B2C 서비스를 운영하기 위한 사내 관리자 사이트입니다.

## Role

프론트엔드 엔지니어로 관리자 화면 구현과 운영 기능 개선에 참여했습니다.

## Implementation

React, TypeScript, Ant Design, GraphQL 기반으로 운영자가 반복적으로 사용하는 화면을 구현했습니다.

## Notes

이 문서는 v1 프로젝트 데이터를 v2 콘텐츠 모델로 옮긴 초안입니다. 상세 기능 범위와 운영 개선 내용은 이후 보강합니다.
