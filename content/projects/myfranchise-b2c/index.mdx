## Overview

마이프차 B2C는 예비 창업자가 프랜차이즈 브랜드를 탐색하고, 정보공개서와 상권 데이터를 확인할 수 있도록 돕는 서비스입니다.

## Role

프론트엔드 엔지니어로 제품 화면 구현, 데이터 연동, UI 개선 작업에 참여했습니다.

## Implementation

Next.js, React, TypeScript 기반으로 주요 화면을 구현하고 GraphQL API와 Apollo Client를 통해 서비스 데이터를 연결했습니다.

## Notes

이 문서는 v1 프로젝트 데이터를 v2 콘텐츠 모델로 옮긴 초안입니다. 상세 문제 정의, 의사결정, 결과 지표는 이후 보강합니다.
