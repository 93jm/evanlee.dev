## Overview

Evanlee.dev v1은 개인 소개와 프로젝트 기록을 공개하기 위해 만든 포트폴리오 블로그입니다.

## Role

기획, 디자인, 프론트엔드 구현, 배포 구성을 직접 담당했습니다.

## Implementation

Next.js 기반의 페이지 구조를 만들고, Vercel 배포와 AWS Route 53 도메인 연결을 구성했습니다.

## Notes

v2 개편에서는 이 경험을 바탕으로 콘텐츠 모델, SEO, 블로그 기능, 인터랙션 구조를 다시 설계합니다.
