## Overview

Evanlee.dev v2는 기존 개인 포트폴리오를 기술 블로그 중심의 공개 제품으로 재구성하는 프로젝트다. 단순히 페이지를 다시 꾸미는 것이 아니라, 소개, 프로젝트, 이력서, 글, 반응 기능이 서로 연결되는 구조를 목표로 한다.

## Problem

v1은 개인 정보를 보여주는 페이지 중심이었다. 하지만 기술 문서, 프로젝트 회고, 경력 서사를 지속적으로 쌓기에는 콘텐츠 모델과 탐색 구조가 충분하지 않았다.

## Role

기획, 정보구조 설계, 프론트엔드 구현, 콘텐츠 모델 설계, SEO 기본 전략 수립을 담당한다.

## Constraints

- 기존 Next.js 기반을 유지한다.
- Firebase, Vercel, AWS domain 구성 전제를 유지한다.
- 디자인 foundation은 SEED Design과 Pretendard를 사용한다.
- SEO와 semantic markdown 요구사항을 초기 단계부터 반영한다.

## Implementation Direction

콘텐츠는 MDX와 frontmatter로 관리한다. 프로젝트도 단순 카드 데이터가 아니라 case study 문서로 작성해, `/projects/[slug]`에서 문제, 역할, 제약, 구현, 결과를 충분히 설명할 수 있게 한다.

## Results

Phase 1의 결과물은 블로그와 프로젝트를 읽는 public loader API다. 이후 Blog Experience Agent와 Portfolio Integration Agent는 같은 콘텐츠 모델을 사용해 화면을 구현할 수 있다.

## Learnings

완성도 높은 개인 사이트를 만들려면 초기에 폴더 구조와 frontmatter 정책을 가볍게라도 고정해야 한다. 그래야 기능이 늘어나도 화면과 데이터가 서로 강하게 얽히지 않는다.
