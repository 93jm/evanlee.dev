## Overview

마이프차 B2B는 프랜차이즈 브랜드 파트너가 서비스를 관리하고 운영할 수 있도록 지원한 제품입니다.

## Role

프론트엔드 구현, 상태 관리, API 연동, 제품 개선 작업에 참여했습니다.

## Implementation

React와 TypeScript 기반으로 화면을 구성하고 GraphQL, Apollo Client, React Query를 활용해 데이터 조회와 화면 상태를 관리했습니다.

## Notes

이 문서는 v1 프로젝트 데이터를 v2 콘텐츠 모델로 옮긴 초안입니다. 상세한 문제 정의와 성과는 이후 보강합니다.
